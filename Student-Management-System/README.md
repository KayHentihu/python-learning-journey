# 🎓 Student Management System

A simple Student Management System built with Python as part of my Python Learning Journey.

## 📌 About

This project is a console-based application for managing student data.

The project was created to practice:

- Python functions
- Classes and objects
- CRUD operations
- Input validation
- File handling
- Modular programming

## ✨ Features

- ➕ Add student data
- 📋 View student data
- ✏️ Edit student data
- 🗑️ Delete student data
- 🔍 Validate student input
- 🚫 Prevent duplicate NIM
- 💾 Save data to `.txt`
- 📂 Load data from `.txt`

## 🛠️ Technologies

- Python
- Object-Oriented Programming (OOP)
- File Handling
- Git & GitHub

## 📂 Project Structure

```text
Student-Management-System/
├── crud.py
├── mahasiswa.txt
├── main.py
├── models.py
├── storage.py
├── validation.py
└── README.md
```

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the program with:

```bash
python main.py
```

## 💾 Data Storage

Student data is stored in `mahasiswa.txt` using the following format:

```text
NIM|Nama|Semester
```

Example:

```text
001|Budi|1
002|Siti|3
003|Andi|2
```
